# ADR-0001 — เขียนใหม่ทั้งหมดด้วย Drizzle + Neon ใน repo เดิม

วันที่ 25 ตุลาคม 2569 · สถานะ: ใช้อยู่ · ที่มา: grilling เรื่อง WorkTrain รุ่นที่ 1

WorkTrain รุ่นเก่า (Next.js 16 + Prisma 7 · ~13,700 บรรทัด · login Entra ตรง · ตำแหน่ง/กลุ่มของตัวเอง) ยังไม่มีผู้ใช้และไม่มีข้อมูล
**ตัดสินว่าเขียนใหม่ทั้งหมด** บน stack เดียวกับ WorkHR / WorkDaily (Next.js + Drizzle + Neon · vitest + PGlite)
ใน repo `WorkTrain` เดิม ผ่านแบรนช์ + PR

## เหตุผล

1. **schema ต้องรื้อเกือบหมดอยู่แล้ว** — login · ตำแหน่ง · กลุ่ม · ข้อสอบ 5 ชุด · เวอร์ชัน · รอบเรียน · การสแกน ไม่มีในของเดิม
   ฐานยังว่าง จึงเป็นจังหวะที่ถูกที่สุดที่จะเปลี่ยน
2. **ระบบพี่น้องที่ TG ดูแลเป็นแบบเดียวกันหมด** — WorkID · WorkHR · WorkDaily ใช้ Drizzle 0.45 + Neon + vitest
   หยิบ SSO · LIFF login · ตัวเรียก WorkGateWay · health · dev-actor · เทสต์ PGlite มาได้ทั้งชุด
3. **ของเดิมไม่มีเทสต์เลย** — แก้ส่วน login/สิทธิ์บนโค้ดที่ไม่มีเทสต์เสี่ยงกว่าเริ่มบนโครงที่มีเทสต์
4. **repo เดิม** — ชื่อ WorkTrain และโปรเจกต์ Vercel ใช้ต่อได้ โค้ดเก่ายังอยู่ใน git history ถ้าต้องหยิบ (เช่น ตัวแก้บทเรียนแบบ block)

## ไม่เลือก

- **ต่อยอดโค้ดเดิมบน Prisma** — เริ่มฟีเจอร์ได้เร็วกว่า แต่เป็นระบบเดียวในเครือที่ต่างแบบ หยิบโค้ดพี่น้องมาตรง ๆ ไม่ได้
  และ migration ของเดิมไม่ตรง schema อยู่แล้ว (4 ไฟล์ ทั้งที่ schema มีตารางมากกว่านั้น)
- **เก็บ UI เดิม เปลี่ยนแค่ชั้นข้อมูลเป็น Drizzle** — ต้องแก้ 49 ไฟล์ที่เรียก Prisma แล้วยังต้องรื้อหน้าส่วนใหญ่ตามข้อ 1 อยู่ดี
- **repo ใหม่** — ต้องตั้ง Vercel · Neon · consumer key ใหม่หมดโดยไม่ได้อะไรเพิ่ม

## ผลที่ตามมา

- ระหว่างเขียนใหม่ `main` ยังเป็นโค้ดรุ่นเก่า จนกว่า PR ของโครงใหม่จะ merge
- ตัวแก้เนื้อหาแบบ block · ระบบล็อกสอบจนดูวิดีโอจบ · forced re-learn ต้องเขียนใหม่ (ดูของเก่าเป็นตัวอย่างได้)
