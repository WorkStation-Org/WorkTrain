# ADR-0009 — จัดอันดับด้วยคะแนนครั้งแรก และไม่เฉลยคำตอบหลังสอบ

วันที่ 25 ตุลาคม 2569 · สถานะ: ใช้อยู่ · ที่มา: grilling เรื่อง WorkTrain รุ่นที่ 1

**ตัดสินว่า** Leaderboard และสถิติหลักใช้**คะแนนครั้งแรก** (เท่ากันใช้ความไว) และหลังส่งแสดงแค่คะแนนกับข้อที่ผิด ไม่บอกคำตอบที่ถูก

## เหตุผล

1. **สอบซ้ำได้ไม่จำกัด** — ถ้าใช้คะแนนสูงสุด สุดท้ายทุกคนได้ 100% เท่ากันหมด อันดับไม่มีความหมาย
2. **มีแค่ 5 ชุด** (ADR-0003) — ถ้าเฉลย คนจะจำเฉลยไปตอบรอบหน้าแทนการกลับไปอ่าน

## ไม่เลือก

- **คะแนนสูงสุด / คะแนนครั้งที่ผ่าน** — ตามข้อ 1
- **เฉลยหลังสอบ** — ตามข้อ 2

## ผลที่ตามมา

- ไม่นับชุดที่ตัวเองสร้างหรืออนุมัติ เพราะรู้เฉลยอยู่แล้ว · TG ไม่ติดอันดับ
- ผู้เรียนที่ติดข้อเดิมซ้ำ ๆ ต้องกลับไปอ่าน — สอดคล้องกับ forced re-learn เมื่อไม่ผ่าน 2 ครั้งติด
