# ADR-0025 — เอกสารประกอบ · เพิ่มเข้าชุดที่ใช้อยู่ได้ทันทีโดยไม่ต้องเริ่มเวอร์ชันใหม่

วันที่ 20 พฤศจิกายน 2569 · สถานะ: ใช้อยู่

เจ้าของขอให้เพิ่มเนื้อหาเข้าชุดได้โดยไม่ต้องตั้งข้อสอบใหม่หรือตั้งค่าใหม่ทั้งหมด — เช่น PDF ไว้เปิดอ่านทบทวน ·
ที่ผ่านมาชุดที่ใช้อยู่เพิ่มไฟล์ได้ทางเดียวคือเริ่มเวอร์ชันใหม่ (อัปทุกไฟล์ใหม่ · AI ออกข้อสอบ 5 ชุด · สรุปสิ่งที่เปลี่ยน · รออนุมัติ · ADR-0008)

**ตัดสินว่า** (เจ้าของเลือก ก ทั้งสามข้อ · 20 พ.ย. 2569)
- เพิ่มชนิดเอกสาร **เอกสารประกอบ** (`documents.kind = 'reference'` — คอลัมน์เป็น text ไม่ต้องมี migration) ·
  รับ **PDF หรือวิดีโอ MP4** (Excel ยังแสดงบนหน้าเรียนไม่ได้) · ไม่รับเป็น Pricelist (Pricelist เป็นชนิดของตัวเอง)
- **ผู้เรียนเปิดอ่าน/ดูได้ ไม่บังคับ** — ไม่นับความคืบหน้า ไม่ต้องครบก่อนสอบ · เซิร์ฟเวอร์ไม่รับความคืบหน้าของเอกสารประกอบ ·
  หน้าเรียนแยกเป็นกลุ่ม "เอกสารประกอบ" ใต้รายการ ตัวเลข "ครบ x/y" นับเฉพาะที่ต้องเรียน ·
  เปิดได้ตามกติกาเดิม: ต้องมีรอบเรียน หรือสอบผ่านแล้ว (ทบทวน · ADR-0020) · ห้ามระหว่างสอบ · ลง `document_views` ทุกครั้ง
- **AI ไม่ใช้ออกข้อสอบ** · ไม่อยู่ในแผนเฉลี่ยข้อสอบ · ไม่อยู่ในรายชื่อไฟล์ของ Template ข้อสอบ
- **ชุดที่ใช้อยู่: ผู้สร้างหรือ TG เพิ่มเข้าเวอร์ชันที่ผู้เรียนเห็นอยู่ได้ทันที** — ไม่เริ่มเวอร์ชันใหม่ ไม่ต้องอนุมัติ ข้อสอบ 5 ชุดเดิมไม่เปลี่ยน ·
  ลงประวัติ `reference_added` `{ documentId, fileName }` ในคราวเดียวกับแถวเอกสาร (`atomic` · จอง id ด้วย `nextval` แบบ ADR-0022) ·
  **ไม่แจ้ง LINE** (ผู้เรียนเห็นเองเมื่อเปิดชุด)
  - ชุดที่ใช้อยู่อัปได้**เฉพาะ**เอกสารประกอบ — เนื้อหาที่ต้องเรียนยังต้องเริ่มเวอร์ชันใหม่ (`canAddReference` ใน set-service)
  - เปลี่ยนชื่อได้ · เปลี่ยนชนิดไม่ได้ (เปลี่ยนเป็นที่ต้องเรียน = เนื้อหาเปลี่ยน ต้องผ่านเวอร์ชันใหม่) · ซ่อน/แสดงได้ตามสวิตช์เดิม
  - **ลบได้เฉพาะที่ยังไม่มีใครเปิด** (`document_views` มีแต่ insert · `reading_progress` อ้างแบบ restrict) — ลงประวัติ `reference_removed` · มีคนเปิดแล้ว = ซ่อนแทน
  - **มีเวอร์ชันใหม่ค้างอยู่** = เอกสารประกอบเข้าเวอร์ชันใหม่ทางปกติ ผู้เรียนเห็นเมื่ออนุมัติ — หน้าเอกสารแสดงเวอร์ชันเดียวเสมอ ไม่มีสองที่ให้อัป
- **ชุดร่าง / เวอร์ชันใหม่ที่ยังไม่ส่ง**: "ใช้ทำอะไร" มีตัวเลือกเอกสารประกอบ · ด่านส่งขออนุมัติ (ทั้งชุดและเวอร์ชันใหม่) ต้องมีคลิปหรือเอกสารที่ต้องเรียน
  อย่างน้อย 1 รายการ (`missingRequiredContent`) — ไม่อย่างนั้นไม่มีใครอ่านครบจนสอบได้
- กติกา "ต้องนับว่าเป็นเนื้อหาที่ต้องเรียน" อยู่ที่เดียว: `requiredForExam()` ใน `src/domain/document.ts` — หน้าเรียน · รายการผู้เรียน ·
  ภาพรวมชุด · ด่าน "ต้องเหลืออย่างน้อย 1 รายการ" (ซ่อน · ย้ายคลิป) · ด่านส่งขออนุมัติ

## เหตุผล

1. **ไฟล์ทบทวนไม่ได้เปลี่ยนสิ่งที่สอบ** — ไม่มีเหตุให้ผู้อนุมัติตรวจข้อสอบใหม่หรือให้คนที่ผ่านแล้วรับทราบ · การเพิ่มเห็นได้ในแท็บประวัติ
2. **ไม่บังคับอ่าน = ไม่กระทบใครที่กำลังเรียน** — คนที่อ่านครบรอสอบอยู่ยังสอบได้ทันที (ต่างจากคลิปที่ TG ย้ายเข้ามา · ADR-0022)
3. **ชนิดเอกสารใหม่แทนคอลัมน์ใหม่** — "ใช้ทำอะไร" คือคำถามเดียวกันอยู่แล้ว · ผู้สร้างตั้งในร่างได้ด้วยตัวเลือกเดิม · ไม่มี migration

## ไม่เลือก

- **ผู้สร้างเลือกรายไฟล์ว่าบังคับหรือไม่** (ข) · **บังคับอ่านก่อนสอบทุกไฟล์** (ค) — เนื้อหาที่ต้องเรียนเปลี่ยนการสอบ ควรผ่านเวอร์ชันใหม่ตาม ADR-0008
- **ผู้อนุมัติต้องกดรับก่อนขึ้น** — เจ้าของเลือกให้ขึ้นทันที ลงประวัติแทน
- **แจ้ง LINE ทุกคนที่ได้รับมอบ** — รบกวนคนที่ผ่านไปแล้วด้วยสิ่งที่ไม่บังคับ
- **ผูกเอกสารประกอบกับชุดแทนเวอร์ชัน** — `documents.version_id` ไม่ว่าง และทุกทางเปิดไฟล์อ่านจากเวอร์ชันที่อนุมัติล่าสุด ·
  ผลคือ **เวอร์ชันใหม่ไม่พาเอกสารประกอบของเวอร์ชันเดิมไปด้วย** (เหมือนไฟล์อื่นทุกไฟล์) — ผู้สร้างอัปใส่เวอร์ชันใหม่อีกครั้ง
