# ADR-0004 — ผู้อนุมัติค่าเริ่มต้นคือหัวหน้าตามผังของผู้สร้าง

วันที่ 25 ตุลาคม 2569 · สถานะ: ใช้อยู่ · ที่มา: grilling เรื่อง WorkTrain รุ่นที่ 1

**ตัดสินว่าผู้อนุมัติไม่ใช่ role ตายตัว** — ระบบตั้งให้เป็นหัวหน้าของผู้สร้างจาก `managerPersonId` ใน WorkID ·
ผู้สร้างเปลี่ยนเป็นรายชุดได้ · ผู้อนุมัติแก้เองได้ ให้ AI ออกใหม่ทีละข้อได้ หรือตีกลับพร้อมความเห็น

## เหตุผล

1. **ระบบใช้ได้ทุกแผนก** — PD ส่ง → PD Mgr · Sales Manager ส่ง → หัวหน้าของ Sales Manager · ไม่ต้องตั้งค่าต่อหมวด
2. **ผังเปลี่ยน ผู้อนุมัติเปลี่ยนตาม** โดยไม่มีใครต้องแก้ใน WorkTrain (ADR-0002)
3. **แก้เล็กไม่ควรวนส่งกลับไปกลับมา** แต่ต้นทางผิดต้องกลับไปแก้ไฟล์ — จึงมีทั้งแก้เองและตีกลับ

## ไม่เลือก

- **ผู้อนุมัติตายตัวต่อหมวด/ประเภท** — ต้องมีคนดูแลตาราง และตกหล่นเมื่อมีแผนกใหม่ใช้ระบบ
- **ตีกลับอย่างเดียว** — คำผิดหนึ่งคำกลายเป็นรอบส่งใหม่ทั้งรอบ

## ผลที่ตามมา

- คนที่ไม่มีหัวหน้าในผัง (ระดับบนสุด) ต้องเลือกผู้อนุมัติเองทุกครั้ง
- ทุกการแก้ของผู้อนุมัติเก็บประวัติ ก่อน/หลัง
