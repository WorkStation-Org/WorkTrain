# ADR-0010 — ไฟล์อยู่ใน R2 แบบ private · Pricelist ดูได้อย่างเดียวพร้อมลายน้ำ

วันที่ 25 ตุลาคม 2569 · สถานะ: ใช้อยู่ · ที่มา: grilling เรื่อง WorkTrain รุ่นที่ 1

ผู้รับมีหลายทีม (ถึงหัวหน้าทีมจัดส่งและ QC) และ Pricelist + เงื่อนไขการขายเป็นข้อมูลลับทางการค้า
**ตัดสินว่า** ทุกไฟล์อยู่ใน R2 แบบ private เปิดด้วย presigned URL อายุสั้นหลังตรวจสิทธิ์ ·
แคตตาล็อกดาวน์โหลดได้ · Pricelist ดูในระบบเท่านั้น มีลายน้ำชื่อ + รหัสพนักงาน + วันเวลาทุกหน้า · log ทุกการเปิด

## เหตุผล

1. **รุ่นเก่าเก็บไฟล์เป็น public URL** — ใครได้ลิงก์ก็เปิดได้ รวมถึงคนที่ลาออกไปแล้ว
2. **ลายน้ำบอกที่มา** ถ้ามีคนถ่ายรูปหน้าจอส่งต่อ — กันไม่ได้ร้อยเปอร์เซ็นต์ แต่ทำให้ไม่กล้า
3. **แคตตาล็อกเป็นเอกสารขายอยู่แล้ว** — ล็อกไว้มีแต่ทำให้เซลทำงานยาก

## ไม่เลือก

- **ดาวน์โหลดได้ทุกไฟล์แบบรุ่นเก่า** — ตามข้อ 1

## ผลที่ตามมา

- Pricelist ต้องแสดงผลเป็นหน้าในระบบ (render ฝั่ง server แล้วใส่ลายน้ำ) ไม่ใช่ส่งไฟล์ต้นฉบับให้เบราว์เซอร์
- ลาออก = หมดสิทธิ์ทันทีผ่าน `session/check` ของ WorkID
