# ADR-0011 — ชนิดของชุดเป็นทะเบียนที่ TG ดูแล · หัวข้อของแม่แบบตั้งชื่อเองได้

วันที่ 8 พฤศจิกายน 2569 · สถานะ: ใช้อยู่ · ที่มา: งานถัดไปข้อ 1 ใน `docs/HANDOFF.md`

รุ่นแรกมีชนิดของชุดแค่สองค่าตายตัว (`learning_sets.kind` = `product` | `general`) และหัวข้อข้อสอบเป็น enum 5 ค่า
ซึ่งเกือบทั้งหมดเป็นเรื่องสินค้า (Spec · ราคา · วัสดุ · การจับคู่ · ทั่วไป) — แต่ WorkTrain ใช้กับการเรียนรู้**ทุกเรื่อง**ของบริษัท

**ตัดสินว่า**
- ชนิดของชุดย้ายไปตาราง `set_kinds` (ชื่อ · แม่แบบข้อสอบ · แนบ Pricelist ได้ไหม · เปิด/ปิด) ที่ `/admin/kinds`
- **TG เท่านั้น**ที่เพิ่ม แก้ เปิด/ปิด — ผู้สร้างเลือกจากชนิดที่เปิดอยู่
- ชุดที่สร้าง**คัดลอก**แม่แบบของชนิด ณ ตอนนั้น (`learning_sets.blueprint` แบบเดิม) — แก้แม่แบบของชนิดทีหลังมีผลกับชุดใหม่เท่านั้น
- หัวข้อเป็นข้อความที่ TG ตั้ง (ไม่เกิน 60 ตัวอักษร) แทน enum · ข้อสอบเดิมที่ใช้รหัสเก่ายังแสดงชื่อเดิมผ่าน `topicLabel()`
- แนบ Pricelist ได้หรือไม่เป็นสวิตช์ของชนิด แทนการผูกกับชนิด "สินค้า"
- ไม่มีการลบชนิด (ชุดอ้างตลอดไป) — ปิดแทน และต้องเปิดไว้อย่างน้อยหนึ่งชนิด

## เหตุผล

1. **TG เป็นผู้ดูแลระบบ** — ถ้าผู้สร้างเพิ่มชนิดเองได้ ทะเบียนจะรกด้วยชื่อซ้ำความหมาย และผู้สร้างยังปรับสัดส่วนของชุดตัวเองได้อยู่แล้ว
2. **ชุดคัดลอกแม่แบบ** — ชุดที่ออกข้อสอบหรืออนุมัติแล้วต้องไม่เปลี่ยนสัดส่วนเพราะ TG แก้ทะเบียน (ข้อสอบ 5 ชุดต้องตรงสัดส่วนของชุด · ADR-0003)
3. **หัวข้อตั้งเอง** — enum เดิมเป็นภาษาสินค้า ชนิดอย่าง "ความปลอดภัย" หรือ "นโยบายบริษัท" ใช้ได้แค่ "ทั่วไป"
4. **ส่งหัวข้อให้ AI เป็นรหัส `T1` `T2` …** แล้วแปลงกลับ — ไม่ต้องพึ่งให้ AI พิมพ์ชื่อไทยกลับมาตรงทุกตัวอักษร
   `checkForms()` ยังปฏิเสธผลที่หัวข้อไม่ตรงช่องเหมือนเดิม

## ไม่เลือก

- **แก้แม่แบบของชนิดแล้วชุดร่างเปลี่ยนตาม** — สับสนว่าชุดไหนเปลี่ยนไม่เปลี่ยน และผู้สร้างอาจปรับสัดส่วนของชุดไว้แล้ว
- **หัวข้อเป็นรายการกลางให้ TG เลือก** — ต้องมีอีกตารางและอีกหน้า โดยไม่ได้อะไรเพิ่มจากการพิมพ์ชื่อในแม่แบบ
- **เปลี่ยนรหัสหัวข้อเดิมในข้อสอบที่มีอยู่เป็นชื่อไทย** — แตะแถวที่อนุมัติแล้วโดยไม่จำเป็น `topicLabel()` แสดงชื่อเดียวกันได้

## ผลที่ตามมา

- migration 0007 สร้าง `set_kinds` พร้อมสองชนิดเดิม (id 1 = "สินค้าใหม่ (PD)" แนบ Pricelist ได้ · id 2 = "ทั่วไป") แล้วย้ายทุกชุดไป `kind_id` · 0008 ลบคอลัมน์ `kind`
- `SEEDED_KIND_IDS` ใน `schema.ts` ชี้สองแถวนี้ · เทสต์ตรวจว่าแม่แบบในฐานตรงกับ `PRODUCT_BLUEPRINT` / `GENERAL_BLUEPRINT`
- ชื่อชนิดอยู่ที่ทะเบียนที่เดียว — แก้ชื่อแล้วชุดเดิมแสดงชื่อใหม่
