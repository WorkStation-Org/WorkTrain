# ADR-0016 — ลบร่าง · ปิดชุดที่ใช้อยู่

วันที่ 13 พฤศจิกายน 2569 · สถานะ: ใช้อยู่

เจ้าของมีร่างที่ไม่ใช้ค้างในรายการ `/sets` และมีชุดที่ใช้อยู่ซึ่งทำชุดใหม่แทนแล้ว — ต้องเอาออกจากรายการได้เอง

**ตัดสินว่า**
- **ลบร่าง** — ผู้สร้าง/TG กด "ลบร่าง" ได้ทั้งในรายการและหัวหน้าชุด (ร่างที่ถูกตีกลับก็ลบได้) · สถานะเป็น `deleted` ·
  หายจากรายการ เปิดหน้าชุดไม่ได้ ผูกเส้นทาง Onboarding ไม่ได้ · ลงประวัติ `deleted`
- **ปิดชุด** — ผู้สร้าง/TG กด "ปิดชุด" ที่หัวหน้าชุดที่ใช้อยู่ · สถานะ `closed` + `closed_at` (spec §2 มีสถานะนี้อยู่แล้ว) ·
  เลิกมอบคนใหม่ เลิกเตือน หายจากหน้าผู้เรียน และ WorkHR ไม่นับเป็นชุดที่ต้องเรียน — ทุกที่กรอง `status = 'active'` อยู่แล้ว ·
  ผลที่สอบไปแล้วยังอยู่ในสถิติ · ในรายการ `/sets` พับไว้ท้ายหน้า "ปิดแล้ว n ชุด" · ลงประวัติ `closed`
- ทั้งสองอย่างถามยืนยันก่อนกด และย้อนกลับไม่ได้จากหน้าจอ · ผู้อนุมัติที่ไม่ใช่ผู้สร้างทำไม่ได้

## ไม่เลือก

- **ลบแถวจริง** — `approval_events` มีแต่ insert (migration 0001) และทุกร่างมีประวัติอย่างน้อย `exams_generated` · ลบแถวชุดไม่ได้โดยไม่ปิด trigger
- **ลบชุดที่ใช้อยู่** — มีการมอบ ครั้งที่สอบ และ log การเปิดเอกสารที่ต้องเก็บ · ปิดให้ผลเดียวกันบนจอโดยไม่ทำลายหลักฐาน
- **เปิดชุดที่ปิดแล้วกลับมา** — ยังไม่มีใครขอ · ทำชุดใหม่แทนได้
- **ลบไฟล์ใน R2 ของร่างที่ลบ** — แถว `documents` ยังอ้าง key อยู่ · ไฟล์ไม่ได้เปิดให้ใครแล้ว
