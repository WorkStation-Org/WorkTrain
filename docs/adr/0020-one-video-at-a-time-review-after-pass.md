# ADR-0020 — ดูคลิปได้ทีละคลิป · ทบทวนได้หลังสอบผ่าน

วันที่ 18 พฤศจิกายน 2569 · สถานะ: ใช้อยู่

เจ้าของพบช่องโหว่: เปิดหลายแท็บแล้วเล่นคนละตอนพร้อมกัน เวลาในทุกคลิปเดินพร้อมกัน ดูครบเร็วกว่าจริงโดยไม่ได้ดูจริง
เพดานเดิม (ADR-0013 · `maxNewSegments`) คิดต่อ heartbeat ต่อเอกสาร — แต่ละแท็บได้เพดานของตัวเอง เปิด 3 แท็บก็เร็ว 3 เท่า
และขอเพิ่ม: สอบผ่านแล้วยังกลับมาดูคลิปทบทวนได้เรื่อย ๆ

**ตัดสินว่า — ทีละคลิป (เซิร์ฟเวอร์ตัดสิน)**
- รอบเรียน (`study_sessions` — หนึ่งคนมีได้รอบเดียว) จองคลิปที่นับอยู่: `video_document_id` + `video_held_at`
  - heartbeat ของคลิปอื่นภายใน 30 วินาทีหลังคลิปที่จองส่งล่าสุด = `video_elsewhere` **ไม่นับอะไรเลย** (ทั้งช่วงและเวลา)
  - ปิดคลิป/เปลี่ยนคลิปในแท็บเดียวกัน = ส่ง `release` ปล่อยทันที · ไม่ปล่อย = หมดเองใน 30 วินาที
  - กันได้ทั้งหลายแท็บและหลายเครื่อง เพราะจองที่รอบเรียน ไม่ใช่ที่เบราว์เซอร์
- งบช่วงวิดีโอก้อนเดียวต่อรอบเรียน (`video_credit_until` · `videoCredit()`): ทุกคลิปรวมกันได้ช่วงละ 5 วินาทีจริง
  (= ดูทีละคลิปที่ 2 เท่า) สะสมได้ไม่เกิน 60 วินาที — ปิดทางคลิปเดียวกันเปิดหลายแท็บ/ส่ง heartbeat ถี่ ๆ
- สองคำขอชนกันพอดี: อัปเดตแบบมีเงื่อนไขบน `video_credit_until` — คำขอที่แพ้ได้ 0 ช่วง เบราว์เซอร์ส่งซ้ำรอบหน้า
- PDF ไม่ติดการจอง

**ตัดสินว่า — เบราว์เซอร์ (ให้คนใช้รู้ ไม่ใช่ด่าน)**
- `BroadcastChannel`: แท็บไหนกดเล่น แท็บอื่นของเว็บเดียวกันหยุด ขึ้นข้อความ และปล่อยการจอง
- ได้ `video_elsewhere`: หยุดเล่น เอาช่วงที่ยังไม่ได้บันทึกออก แล้วโหลดตัวเล่นใหม่ที่จุดเดิม (ล้าง `video.played` —
  ไม่อย่างนั้นช่วงที่เล่นตอนชนกันถูกเก็บกลับเข้าคิว)

**ตัดสินว่า — ทบทวนหลังผ่าน**
- ผ่านแล้วและยังไม่ถูกตัดจบ (`canReview`) = เปิดคลิป/เอกสารได้โดยไม่ต้องมีรอบเรียน (ไม่สแกน) · หน้าเรียนเป็นโหมดทบทวน
- ทบทวนไม่ส่ง heartbeat ไม่นับเวลา กรอ/เร่งได้อิสระ · การเปิดยังลง `document_views` ทุกครั้ง (Pricelist ยังประทับลายน้ำ)
- ผ่านแล้วแต่ถูกตัดจบ (ADR-0017 — ออกจากผู้รับ/ออกจากบริษัท) ไม่ได้ทบทวน — เห็นแค่ว่าผ่าน
- ผ่านแล้วแต่ค้างเวอร์ชันใหม่ (ADR-0008) ยังใช้ทางเดิม: เริ่มรอบเรียนแล้วนับตามปกติ

## ไม่เลือก

- **กันที่เบราว์เซอร์อย่างเดียว** (BroadcastChannel/localStorage) — คนละเครื่อง/คนละเบราว์เซอร์ไม่เห็นกัน และแก้ JavaScript ข้ามได้
- **งบเวลาอย่างเดียว ไม่จองคลิป** — สองคลิปที่ 1 เท่าพร้อมกันรวมเป็น 2 เท่า อยู่ในงบพอดี จึงยังดูสองคลิปพร้อมกันได้
- **ทบทวนต้องสแกน** — ไม่มีอะไรนับหรือตัดสิน การยืนยันตัวตนไม่ได้ป้องกันอะไรเพิ่ม แต่ทำให้คนไม่กลับมาทบทวน
