# ADR-0005 — WorkTrain มอบ training ตามตำแหน่งเอง · WorkHR ดึงผลไปติ๊ก checklist

วันที่ 25 ตุลาคม 2569 · สถานะ: ใช้อยู่ · ที่มา: grilling เรื่อง WorkTrain รุ่นที่ 1

Training พ่วงกับใบ Onboarding ของ WorkHR **ตัดสินว่า WorkTrain เป็นคนมอบ** — TG ผูกชุดการเรียนรู้กับตำแหน่ง
คนใหม่หรือคนที่ย้ายตำแหน่ง (เห็นจาก sync ผัง WorkID) ได้รับมอบอัตโนมัติ ·
WorkTrain เปิด API สถานะรายคน · ข้อใน checklist ของ WorkHR ติ๊กเองจาก API นั้น แบบเดียวกับข้อที่ติ๊กเองจาก WorkID

## เหตุผล

1. **TG รู้ดีที่สุดว่าตำแหน่งไหนต้องเรียนอะไร** — HR ไม่ต้องจำรายชื่อชุดการเรียนรู้
2. **ใช้ได้กับการย้ายตำแหน่งด้วย** ไม่ใช่แค่คนเข้าใหม่ — ใบ checklist ของ WorkHR ไม่ได้เปิดทุกครั้งที่ย้าย
3. **ทิศทางเดียว** — WorkHR อ่าน WorkTrain · WorkTrain ไม่เขียนเข้า WorkHR (กติกาเครือข้อ 2)

## ไม่เลือก

- **HR สั่งจากใบ checklist ว่าคนนี้ต้องเรียนอะไร** — ตามข้อ 1–2

## ผลที่ตามมา

- คนใหม่ยังไม่มีอีเมลตอนที่ใบเปิด (WorkID ADR-0003) — การมอบเกิดเมื่อมีตัวตนใน WorkID แล้ว ข้อใน checklist จึงค้างไปก่อน
- ต้องมีรหัสตำแหน่งจาก WorkHR ผ่าน WorkID ก่อนเปิดใช้ (spec §6.1)
- งานฝั่ง WorkHR (ข้อ checklist แบบติ๊กเองจาก WorkTrain) อยู่ใน repo ของ WorkHR
