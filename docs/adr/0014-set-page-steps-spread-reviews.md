# ADR-0014 — หน้าชุดเป็นแถบขั้นตอน · เฉลี่ยข้อสอบตามไฟล์ · "ตรวจแล้ว" ต่อคน · เพิ่มผู้รับให้ชุดที่ใช้อยู่

วันที่ 12 พฤศจิกายน 2569 · สถานะ: ใช้อยู่ · แทนส่วน "แก้ผู้รับได้เฉพาะร่าง" ของ spec §5

เจ้าของใช้หน้า `/sets/[id]` แล้วติดหลายจุด: แก้ข้อสอบแล้วหน้าโหลดใหม่ ทุกชุดปิดหมด ต้องเปิดหาข้อเดิม ·
เลือกผู้รับต้องไล่ checkbox ยาว · ผู้อนุมัติเป็น dropdown ทั้งบริษัท · AI ออกข้อสอบไม่ทั่วทุกไฟล์ ·
ชุดที่ใช้อยู่เพิ่มผู้รับไม่ได้ · หน้ายาวต้องเลื่อนผ่านทุกส่วน (mockup "รอบ 2" + "หน้ารวม")

**ตัดสินว่า**
- หน้าเดียวเหมือนเดิม แต่แบ่งเป็นขั้น ตั้งค่า → เอกสาร → ข้อสอบ → ผู้รับ (→ ผู้เรียน) → ประวัติ ตาม `?tab=` · แต่ละขั้นบอกสถานะในตัว ·
  ทุก action ส่ง `tab` กลับมา บันทึกแล้วอยู่ขั้นเดิม
- แก้ข้อสอบ / ให้ AI ออกข้อใหม่ / "ตรวจแล้ว" เป็น action ที่คืนผล ไม่ redirect — การ์ดของข้อนั้นอยู่ที่เดิม ชุดที่เปิดจำใน `?form=`
- **"ตรวจแล้ว" ต่อคนต่อข้อ** (ตาราง `question_reviews` · migration 0013) — แก้ข้อเอง = ตรวจแล้ว · ให้ AI ออกข้อใหม่ = ล้างของทุกคน ·
  แสดงจำนวนให้ผู้อนุมัติ/ผู้สร้างเห็น **ไม่บังคับ** ก่อนส่งหรืออนุมัติ
- **เฉลี่ยข้อสอบ** (`learning_sets.spread_mode` · `documents.exam_weight`): `file` (ค่าตั้งต้น) เท่ากันทุก PDF · `topic` ให้ AI กระจายตาม blueprint เหมือนเดิม ·
  `custom` ตามน้ำหนัก 0–5 ต่อไฟล์ — `spreadPlan()` แบ่ง 50 ข้อตามน้ำหนักแล้วแจกวนชุด 1→5 ทุกชุดได้ 10 ข้อพอดี
  (10 ไฟล์ = ไฟล์ละ 1 ข้อต่อชุด) · ส่งเป็นตัวเลขในคำสั่งของ AI · หลังออก `coverage()` นับจาก `source_ref` แสดงช่องที่ไม่ตรงแผน (ไม่ปฏิเสธผลของ AI)
- **ผู้รับของชุดที่ใช้อยู่แก้ได้** (ผู้สร้าง/TG) — คนที่ตรงเงื่อนไขใหม่ได้รับมอบทันที (`syncAssignments` + แจ้ง LINE เหมือนตอนอนุมัติ) ·
  คนที่หลุดเงื่อนไข **เก็บการมอบเดิมไว้** (spec §5 เดิม) · หน้าจอสรุปก่อนบันทึก · ลงประวัติ `audience_changed`
- ตัวเลือกผู้รับ: ค้นหา + แท็บ ตำแหน่ง / ทีม / หัวหน้าทีม / **รายคน** (ฐานรองรับ `person` อยู่แล้ว) · รายชื่อคำนวณสดในเบราว์เซอร์ด้วย `resolveAudience` ตัวเดียวกับเซิร์ฟเวอร์
- ผู้อนุมัติค้นหาได้ (ชื่อ · ชื่อเล่น · ตำแหน่ง · ทีม) · หัวหน้าของผู้สร้างขึ้นเป็นข้อแนะนำ (ADR-0004)
- เอกสารต้นทาง: ลากวางหลายไฟล์ ดูชนิดเอง · วิดีโอได้ปกอัตโนมัติจากเฟรม 10% ของไฟล์ในเครื่อง · แก้ชื่อที่ผู้เรียนเห็น / ใช้ทำอะไร / น้ำหนัก / ลำดับ (ปุ่มขึ้น-ลง)

## ไม่เลือก

- **ยกเลิกการมอบของคนที่หลุดเงื่อนไข** — ต้องแตะสถิติ การเตือน และหน้าผู้เรียน · ยังไม่มีใครขอจริง
- **บังคับตรวจครบทุกข้อก่อนอนุมัติ** — ผู้อนุมัติบางคนตรวจแบบสุ่ม · ตัวนับพอให้รู้ว่าเหลือเท่าไร
- **ปฏิเสธผลของ AI เมื่อไม่ตรงแผนเฉลี่ย** — `source_ref` เป็นข้อความอิสระ จับไฟล์พลาดได้ · ให้คนเห็นแล้วแก้ทีละข้อดีกว่าออกใหม่ทั้ง 50 ข้อ
- **แยกเป็นหลายหน้า** — ลิงก์จาก LINE ชี้ `/sets/[id]` อยู่แล้ว · แท็บใน URL เดียวพอ
