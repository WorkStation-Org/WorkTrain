# ADR-0018 — TG อนุมัติแทนผู้อนุมัติ · ผู้อนุมัติเพิ่มผู้รับได้

วันที่ 16 พฤศจิกายน 2569 · สถานะ: ใช้อยู่ · แก้ส่วน "ผู้อนุมัติไม่ใช่ role · อนุมัติได้เฉพาะคนที่ระบุในชุด" ของ ADR-0004
และส่วน "แก้ผู้รับได้เฉพาะผู้สร้าง/TG" ของ ADR-0014

ชุดที่รอผู้อนุมัติไม่ว่างค้างอยู่ TG ทำต่อให้ไม่ได้ · ผู้อนุมัติเห็นว่าควรส่งให้ทีมอื่นด้วยแต่ต้องตีกลับให้ผู้สร้างเพิ่มเอง
(ตกลงกันในรอบถามตอบ 16 พ.ย. 2569)

**ตัดสินว่า**
- **TG (role `admin`) ทำทุกอย่างของผู้อนุมัติได้กับทุกชุด** ไม่ว่าชุดระบุใครเป็นผู้อนุมัติ — ชุดใหม่และเวอร์ชันใหม่:
  อนุมัติ · ตีกลับ · เลือกอ่านเพื่อรับทราบ/เรียนรู้และทดสอบ · แก้/ให้ AI ออกข้อใหม่ · Import ข้อสอบส่วนที่เปลี่ยน
  (`approverRole()` คืน `"approver"` หรือ `"tg"`) · ไม่เพิ่ม role ใหม่ที่ WorkID
- TG อนุมัติชุดที่ตัวเองสร้างหรือตัวเองกดส่งได้ — ประวัติลง `ownSet` ให้เห็นชัด (กติกาสองคนของผู้อนุมัติที่ระบุยังเหมือนเดิม)
- **ประวัติ** — `approval_events.detail.onBehalfOf` = ผู้อนุมัติที่ระบุไว้ ณ ตอนกด · แท็บประวัติขึ้น "(TG แทน …)" ·
  ผู้อนุมัติที่ระบุกดเองไม่มี detail เหมือนเดิม
- **แจ้ง** — ผู้สร้างได้ "✅ (ชื่อ) (TG) อนุมัติแทน (ผู้อนุมัติ)" · ผู้อนุมัติตัวจริงได้ "ℹ️ … อนุมัติแทนคุณแล้ว" · ไม่ส่งหาคนที่กดเอง
- หน้าชุดบอก TG ก่อนกดว่ากำลังตรวจแทนใคร · หน้า `/sets` จัดงานที่รออนุมัติ (ชุดใหม่ · เวอร์ชันใหม่) ไว้บนสุด "รออนุมัติ (n)"
  พร้อมบอกว่ารอใครมากี่วัน · ทุกคนเห็นเฉพาะชุดที่ตัวเองเห็นอยู่แล้ว (TG ทุกชุด)
- **ผู้อนุมัติเพิ่มผู้รับได้** ทั้งตอนรออนุมัติและตอนชุดใช้อยู่ (`audienceMode() = "addOnly"`): เพิ่มเงื่อนไขได้ ·
  เอาเงื่อนไขของผู้สร้างออกไม่ได้ ลบได้เฉพาะที่ตัวเองเพิ่ม (`audience_rules.added_by_person_id` · migration 0016) ·
  ลงประวัติทุกครั้ง (`audience_changed` · `detail.by = "approver"`) · ผู้สร้างได้ LINE "➕ … เพิ่มผู้รับ … (+n คน)" ·
  ชุดที่ใช้อยู่มอบ/ตัดจบทันทีตาม ADR-0017 · TG แก้ผู้รับได้ทุกเงื่อนไขตอนรออนุมัติด้วย

## ไม่เลือก

- **role ใหม่ "ผู้บริหาร"** — ต้องเพิ่มที่ WorkID · TG คือคนที่ตามงานค้างอยู่แล้ว
- **TG อนุมัติชุดของตัวเองไม่ได้** — เจ้าของเลือกให้ทำได้ เพราะ TG มีน้อยคน · ใช้ประวัติที่บอกชัดแทนการห้าม
- **บังคับเหตุผลเมื่อ TG อนุมัติชุดของตัวเอง** — เพิ่มขั้นตอนโดยไม่ได้ข้อมูลเพิ่ม (ประวัติบอกแล้วว่าใครกด)
- **ผู้อนุมัติแก้ผู้รับได้ทุกเงื่อนไข** — ผู้สร้างเป็นเจ้าของชุด · ผู้อนุมัติเติมได้แต่ไม่ควรลบสิ่งที่ผู้สร้างตั้งใจไว้
