# ADR-0026 — ปก PDF อัตโนมัติจากหน้าแรก · ตัวอ่าน PDF ของผู้เรียนเปิดทีละหน้า

วันที่ 20 พฤศจิกายน 2569 · สถานะ: ใช้อยู่

เจ้าของขอ (1) ให้ PDF มีปกอัตโนมัติเหมือนคลิป (2) ให้ตัวอ่าน PDF ฝั่งผู้เรียนกดเลื่อนซ้าย/ขวาแทนเลื่อนลง และให้หน้าอยู่ในกรอบของตัวแสดงพอดี

**ตัดสินว่า — ปก PDF**
- ปก = **หน้าแรก** วาดด้วย pdfjs ในเบราว์เซอร์ของผู้สร้าง/TG เป็น JPEG กว้าง ≤ 640 px · ≤ 512 KB (`sets/[id]/pdf-cover.ts`) ·
  ส่งทางเดียวกับปกวิดีโอ (`setDocumentCover` · `ms` = 0) · เก็บข้างไฟล์ใน R2 (`documents.cover_key`) — ไม่มี migration
- ตอนอัป: วาดจากไฟล์ในเครื่อง · PDF ที่อัปไว้ก่อนแล้วยังไม่มีปก: ทำให้เองทีละไฟล์เมื่อผู้สร้าง/TG เปิดแท็บเอกสาร (ลิงก์ `previewLink` · bucket รับ GET แบบ CORS อยู่แล้ว) ·
  ทำไม่ได้ก็ข้าม ไม่วนลองซ้ำในการเปิดหน้าครั้งเดียวกัน
- **Pricelist ไม่มีปก** — ภาพหน้าแรกไม่มีลายน้ำ จะหลุดราคาออกนอกตัวอ่านที่ประทับลายน้ำ (ADR-0010) · เปลี่ยนไฟล์เป็น Pricelist = ลบปกทั้งในฐานและที่เก็บ
- แสดงในรายการเอกสาร · รายการเนื้อหาในหน้าเรียน · การ์ดทำต่อ · การ์ดชุด (ชุดที่ไม่มีวิดีโอใช้ปก PDF) — ภาพชิดบน (`object-top`) ให้เห็นหัวเรื่อง

**ตัดสินว่า — ตัวอ่าน PDF ของผู้เรียน**
- เปิด**ทีละหน้า**ในกรอบสูงคงที่ `min(68dvh, 620px)` — ย่อให้พอดีทั้งกว้างและสูง ไม่ต้องเลื่อนลง
- เปลี่ยนหน้า: ปุ่ม ‹ ก่อนหน้า / ถัดไป › · กดครึ่งซ้าย/ขวาของกรอบ · ลูกศรซ้าย/ขวา (ยกเว้นตอนพิมพ์ในช่องค้นหา) · ปัดบนมือถือ · แถบหน้ากดข้ามได้ (เขียว = เปิดแล้ว)
- **หน้าที่วาดขึ้นจอ = เปิดแล้ว** (เดิม: เห็นเกินครึ่งตอนเลื่อน) · เปิดมาที่หน้าแรกที่ยังไม่ได้อ่าน · เซิร์ฟเวอร์ยังเป็นคนตัดสินว่าครบ (ไม่เปลี่ยน)
- ตัวดูของผู้สร้าง/ผู้อนุมัติ (`doc-preview`) ยังเลื่อนลงตามเดิม — ตรวจเนื้อหาทั้งเล่มเร็วกว่า

## ไม่เลือก

- **วาดปกฝั่งเซิร์ฟเวอร์** — function ของ Vercel ไม่มี canvas (เหตุผลเดียวกับปกวิดีโอ · ADR-0013)
- **ปก Pricelist แบบเบลอ/มีลายน้ำ** — ไม่มีใครขอ · ไอคอนเอกสารพอ
- **นับหน้าเมื่อเปิดค้างไว้ x วินาที** — เดิมนับเมื่อเห็นก็พอ · ไม่เพิ่มกติกาที่ผู้เรียนต้องเข้าใจ
