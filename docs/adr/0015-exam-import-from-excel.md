# ADR-0015 — Import ข้อสอบจาก Template Excel · ผ่านด่านเดียวกับ AI · แทนทั้งหมดในครั้งเดียว

วันที่ 13 พฤศจิกายน 2569 · สถานะ: ใช้อยู่ · ที่มา: grilling เรื่องปุ่ม Import ข้อสอบ

AI อ่านได้แค่ PDF — ชุดที่มีแต่วิดีโอ (ADR-0013) ออกข้อสอบไม่ได้เลย และเวอร์ชันใหม่แบบ**เรียนรู้และทดสอบ**ของชุดแบบนี้อนุมัติไม่ได้
เพราะต้องมีข้อสอบส่วนที่เปลี่ยนก่อน · ผู้สร้างบางคนอยากเขียนข้อสอบเองหรือเกลาของ AI ใน Excel

**ตัดสินว่า**
- ปุ่ม **Template** โหลด .xlsx ของชุดนั้น · ปุ่ม **Import** นำไฟล์ที่กรอกแล้วเข้า — ทั้งข้อสอบชุดเต็ม (5 × 10) และข้อสอบส่วนที่เปลี่ยน (5 × 5)
- **Import = แทนทั้งหมดในครั้งเดียว** · ไม่ผ่านแม้ข้อเดียวไม่ลงอะไร ของเดิมไม่หาย · ผ่านแล้ว "ตรวจแล้ว" ของทุกข้อหายตามข้อเดิม
- **ด่านเดียวกับผลของ AI** — `checkForms` เป็นด่านสุดท้ายเสมอ (4 ตัวเลือกไม่ซ้ำ · เฉลยข้อเดียว · หัวข้อ×ระดับตรงแม่แบบ · คำถามไม่ซ้ำข้ามชุด · มีที่มา)
  แต่ก่อนถึงด่านนั้น `parseSheet` ตรวจทุกแถวแล้ว**บอกทุกจุดพร้อมเลขแถวใน Excel** — คนพิมพ์ 50 แถวผิดหลายจุดพร้อมกัน
- Template สร้างใหม่ทุกครั้งตาม**แม่แบบข้อสอบของชุด** — ชุดที่ · ข้อ · หัวข้อ · ระดับ เติมไว้และล็อก · จับคู่ด้วย (ชุดที่, ข้อ) ไม่ใช่ลำดับแถว
  มีข้อสอบอยู่แล้วก็เติมลงไปด้วย (แก้แล้ว import กลับได้ · ใช้เป็นสำรองก่อนแทนได้)
- ที่มาแยกเป็น **ไฟล์** (dropdown เอกสารที่แนบในเวอร์ชัน) + **ตำแหน่ง** · บังคับทั้งคู่ · ลงฐานเป็น `source_ref` = "ไฟล์ ตำแหน่ง"
  แถบเฉลี่ยตามไฟล์ (`coverage`) จึงนับถูกทุกข้อ · แผนเฉลี่ย**ไม่บังคับ**กับไฟล์ที่ import (มีไว้สั่ง AI)
- **ไม่ต้องมี PDF** — แค่ต้องมีเอกสารอย่างน้อย 1 ไฟล์ให้อ้างเป็นที่มา
- สิทธิ์ตามคนที่ออกข้อสอบส่วนนั้นด้วย AI อยู่แล้ว: ชุดเต็ม = ผู้สร้าง/TG ตอนร่างหรือเวอร์ชันใหม่ที่ยังไม่ส่ง ·
  ส่วนที่เปลี่ยน = ผู้อนุมัติหลังเลือก "เรียนรู้และทดสอบ" · **ผู้อนุมัติ import ชุดเต็มไม่ได้** (คนตรวจกับคนเขียนจะเป็นคนเดียวกัน — แก้รายข้อหรือตีกลับแทน)
- ประวัติได้ `exams_imported` (ชื่อไฟล์) และ `exams_generated` (AI ออกทั้ง 5 ชุด — ก่อนหน้านี้ไม่ได้ลง) · ตอบได้เสมอว่าข้อสอบชุดปัจจุบันมาจากไหน
- ไฟล์เป็น **XLSX** (exceljs · `src/lib/exam-sheet.ts` ที่เดียวที่แตะ) · ไม่เกิน 900 KB (server action รับได้ 1 MB)

## ไม่เลือก

- **CSV** — Excel บันทึกเป็น ANSI แล้วภาษาไทยกลายเป็น `????` ถ้าไม่เลือก "CSV UTF-8" · ใส่ dropdown / ล็อกคอลัมน์ไม่ได้
- **Import บางชุด หรือผสมกับของ AI** — เสียความยุติธรรมของ ADR-0003 ได้ง่าย · การแก้รายข้อมีอยู่แล้วในหน้าข้อสอบ
- **Template กลางไฟล์เดียว** — พิมพ์ชื่อหัวข้อผิดนิดเดียวก็ไม่ผ่าน · แม่แบบเป็นของแต่ละชุด
- **ขั้นดูตัวอย่างก่อนยืนยัน** — ต้องพักไฟล์ไว้ที่เซิร์ฟเวอร์ · หน้าข้อสอบหลัง import คือตัวอย่างอยู่แล้ว และมีกล่องยืนยันก่อนแทน

## ผลที่ตามมา

- แก้แม่แบบข้อสอบของชุดหลังโหลด Template ไปแล้ว ไฟล์เก่า import ไม่ผ่าน ("หัวข้อ/ระดับไม่ตรง — กด Template เพื่อโหลดใหม่")
- การแทนทั้งหมดไม่ใช่ atomic (ต้องใช้ id ของคำถามก่อนลงตัวเลือก — เหมือน `generateExams`) · ตรวจผ่านหมดก่อนค่อยลบของเดิม
- ชุดที่ผสม PDF กับวิดีโอ: แถบเฉลี่ยตามไฟล์นับเฉพาะ PDF (แผนของ AI) — ข้อที่ import จากวิดีโอขึ้นเป็น "ระบุไฟล์ไม่ได้"
