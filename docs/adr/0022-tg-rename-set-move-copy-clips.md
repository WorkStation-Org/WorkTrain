# ADR-0022 — TG เปลี่ยนชื่อชุด · ย้าย/คัดลอกคลิปไปชุดอื่น

วันที่ 18 พฤศจิกายน 2569 · สถานะ: ใช้อยู่

เจ้าของขอให้ TG แก้ชื่อชุดการเรียนรู้ได้ และย้ายหรือคัดลอกคลิปในชุดหนึ่งไปใส่อีกชุดได้

**ตัดสินว่า — เปลี่ยนชื่อชุด**
- TG เปลี่ยนชื่อได้**ทุกสถานะ** (ร่าง · รออนุมัติ · ใช้อยู่ · ปิดแล้ว) ยกเว้นร่างที่ลบแล้ว — ที่ขั้นตั้งค่าของหน้าชุด
  · ผู้สร้างยังแก้ชื่อร่างของตัวเองในฟอร์มตั้งค่าได้ตามเดิม
- ทุกทางที่เปลี่ยน `learning_sets.title` ลงประวัติ `renamed` `{ from, to }` (`approval_events` มีแต่ insert)
- **ไม่มีที่ไหนเก็บชื่อชุดแบบ snapshot** — หน้าผู้เรียน · Dashboard · export CSV · WorkHR (`trainingStatus` ส่ง `setId` คู่ชื่อ) ·
  ข้อความ LINE รอบถัดไป (รวมที่ส่งซ้ำ — ประกอบข้อความใหม่จากชื่อปัจจุบัน) อ่านชื่อใหม่ทันที
  · ข้อความ LINE ที่ส่งไปแล้ว (`notifications.text`) คงชื่อเดิม เพราะเป็นสำเนาของสิ่งที่ส่งไปจริง · ไม่แจ้งผู้เรียนเรื่องเปลี่ยนชื่อ

**ตัดสินว่า — ย้าย/คัดลอกคลิป**
- TG เท่านั้น · เฉพาะ**คลิปวิดีโอ** (PDF ผูกกับข้อสอบที่ AI ออก — ยังไม่มีใครขอ) · ทีละคลิป จากแผงของคลิปในขั้นเอกสาร
- **คัดลอกไฟล์เสมอ** — วิดีโอและปก copy ใน R2 (CopyObject ฝั่งเซิร์ฟเวอร์ · ถึง 5 GB ในครั้งเดียว) เป็น key ใหม่ใต้ชุดปลายทาง
  `sets/<ชุดปลายทาง>/v<n>/…` แล้วลงแถว `documents` ใหม่ · ชื่อ · ความยาว · จำนวนช่วง · ปก · ใช้ทำอะไร ไปด้วย ·
  **ต่อท้าย**ชุดปลายทาง (เป็นตอนสุดท้าย) · ชุดปลายทางมีคลิปชื่อและขนาดเดียวกันอยู่แล้ว = ไม่ให้ทำซ้ำ
- **ชุดปลายทางรับได้:** ร่าง (เวอร์ชันแรก) · ใช้อยู่ — ลงเวอร์ชันที่ผู้เรียนเห็นอยู่ หรือเวอร์ชันใหม่ที่ยังไม่ส่ง (ผู้เรียนเห็นเมื่ออนุมัติ)
  · **รับไม่ได้:** รออนุมัติ · มีเวอร์ชันใหม่รออนุมัติ (เนื้อหาที่กำลังตรวจต้องไม่เปลี่ยนเงียบ ๆ — อนุมัติหรือตีกลับก่อน) · ปิด · ลบ
- **คลิปที่ลงเวอร์ชันที่ผู้เรียนเห็นอยู่ ขึ้นทันที** ผลเหมือนกดสวิตช์ "แสดง" (เจ้าของเลือก ก · 18 พ.ย. 2569):
  ผู้เรียนที่ยังไม่ผ่านต้องดูคลิปนี้ครบก่อนสอบ (คนที่ดูครบรอสอบอยู่ก็ต้องดูเพิ่ม · ครั้งที่สอบที่ค้างอยู่ไม่กระทบ) ·
  คนที่ผ่านแล้วไม่ต้องทำอะไร (ทบทวนได้) · หน้าจอบอกจำนวนผู้เรียนที่ยังไม่ผ่านก่อนกด
- **ย้าย = คัดลอก + เอาออกจากชุดเดิม** (เจ้าของเลือก ก · 18 พ.ย. 2569):
  - เวอร์ชันที่ยังแก้ได้ (ร่าง · เวอร์ชันใหม่ที่ยังไม่ส่ง) และยังไม่มีใครเรียน = **ลบแถวและไฟล์**
  - นอกนั้น = **ซ่อน** — `reading_progress` อ้างเอกสารแบบ restrict และ `document_views` มีแต่ insert จึงลบแถวที่มีคนเรียนแล้วไม่ได้ ·
    ไม่เปลี่ยน `version_id` ไปชุดอื่น (ความคืบหน้า/log การเปิดจะย้ายชุดตาม) · ผลเหมือนซ่อนเอง: คนที่ยังไม่ผ่านไม่ต้องดูแล้ว ·
    คนที่ผ่านแล้วทบทวนคลิปนี้ในชุดเดิมไม่ได้ · ต้องเหลือเนื้อหาให้ผู้เรียนอย่างน้อย 1 รายการ
  - ชุดที่ปิดแล้ว = คัดลอกได้อย่างเดียว
- ลงประวัติทั้งสองชุดในคราวเดียว (`atomic`): ชุดเดิม `clip_sent` · ชุดปลายทาง `clip_received` (`ClipTransferDetail` — โหมด · คลิป · อีกชุด · ซ่อน/ลบ)
  · จอง id คลิปใหม่ด้วย `nextval` ก่อน batch เพื่อให้ประวัติอ้างคลิปใหม่ได้
- ลำดับ: copy ไฟล์ก่อนแล้วค่อยลงฐาน — ลงฐานล้ม = ลบไฟล์ที่ copy ไว้ทิ้ง · ย้ายแบบลบ = ลบไฟล์เดิมหลังลงฐานแล้ว (ลบไม่ได้ก็แค่เหลือไฟล์ที่ไม่มีใครอ้าง เหมือน ADR-0016)
- ตรวจสิทธิ์สองชั้น: `requireAdmin()` ใน action และ `actor.role === "admin"` ใน service (`renameSet` · `transferClip` · `clipTargets`)

## ไม่เลือก

- **ใช้ไฟล์ R2 ร่วมกันสองชุด** — `documents.object_key` เป็น unique · ลบคลิปในร่างหนึ่งจะลบไฟล์ของอีกชุด · key บอกชุดผิด
- **ย้ายด้วยการเปลี่ยน `version_id`** — ความคืบหน้า · log การเปิด · ประวัติของผู้เรียนชุดเดิมจะไปโผล่ในชุดใหม่ และผู้เรียนชุดใหม่ได้เครดิตจากของคนอื่น
- **คลิปเข้าชุดที่ใช้อยู่แบบซ่อนไว้ก่อน** (ข) · **ไม่บังคับดู** (ค) · **ต้องผ่านเวอร์ชันใหม่เท่านั้น** (ง) — เจ้าของเลือกให้ขึ้นทันทีเหมือนสวิตช์แสดง
- **ย้ายออกจากชุดที่ใช้อยู่ไม่ได้ ให้คัดลอกอย่างเดียว** — เจ้าของเลือกให้ย้ายได้ โดยชุดเดิมซ่อนคลิป
- **เก็บชื่อชุดเดิมไว้ในข้อความ/รายงาน** — ไม่มีใครต้องการชื่อเก่า · ประวัติมี from/to อยู่แล้ว
- **เลือกตำแหน่งในชุดปลายทาง** — ชุดที่ใช้อยู่ยังเลื่อนลำดับไม่ได้อยู่แล้ว · ต่อท้ายตรงกับ "เพิ่มตอนใหม่" · ร่างเลื่อนเองได้
