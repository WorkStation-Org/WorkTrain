# ADR-0017 — ตัดจบการมอบเมื่อไม่ตรงเงื่อนไขแล้ว · รวมข้อความต่อคน

วันที่ 16 พฤศจิกายน 2569 · สถานะ: ใช้อยู่ · แทนส่วน "คนที่หลุดเงื่อนไขเก็บการมอบเดิมไว้" ของ ADR-0014 และ spec §5

เจ้าของเห็นแท็บผู้เรียนของชุดที่ใช้อยู่ยังมี Sales ที่ลาออกไปแล้ว และคนที่ย้ายทีมแล้วยังถูกเตือนให้เรียนหลักสูตรที่ไม่ใช่ของทีมตัวเอง ·
พนักงานใหม่ที่ได้หลายชุดพร้อมกันได้ LINE แยกทีละชุด (ตกลงกันในรอบถามตอบ 16 พ.ย. 2569)

**ตัดสินว่า**
- **ตัดจบ** = การมอบที่ผู้เรียนไม่ตรงเงื่อนไขผู้รับ (หรือเส้นทาง Onboarding) ของชุดแล้ว — ไม่ว่าเพราะลาออก ย้ายทีม/ตำแหน่ง
  ผู้สร้างแก้เงื่อนไข หลุดจากกลุ่มเฉพาะกิจ หรือ TG เอาชุดออกจากเส้นทาง · ลง `assignments.ended_at` + `end_reason`
  (`left_org` / `not_in_audience`) · **ไม่ลบแถว** ผลสอบยังอยู่ (migration 0015)
- ตัดจบแล้ว: หยุดเตือน · ชุดหายจาก "ชุดที่ต้องเรียน" และเข้าต่อไม่ได้ · ส่ง LINE "ไม่ต้องเรียนแล้ว" เฉพาะคนที่ยังไม่ผ่านและยังอยู่ในผัง
- คนที่ **สอบผ่านแล้ว** ค่อยหลุดเงื่อนไข — ตัดจบเหมือนกัน แต่ยังแสดงว่าผ่านและนับใน x/y · ไม่ถูกแจ้งเวอร์ชันใหม่อีก
- ลงวันที่ตัดจบตอนรอบ sync: cron 09:00 และทันทีที่กดบันทึกผู้รับ · คนลาออกยังถูกซ่อนสดระหว่างวันจากผังปัจจุบัน
- **กลับมาตรงเงื่อนไข** = เปิดการมอบเดิม: ล้างวันที่ตัดจบ · `assign_round + 1` · นับวันที่ได้รับมอบและกำหนดส่งใหม่ · ความคืบหน้าเดิมเก็บไว้ ·
  LINE "ได้รับมอบอีกครั้ง" · dedupe key ของข้อความวันที่ 0 และการเตือนแยกตามรอบ (`remind-day3:12:r2`)
- **ด่านกันผังเพี้ยน** (เฉพาะรอบอัตโนมัติ) — จะตัดจบเกิน 20 การมอบ หรือเกิน 10% ของการมอบที่ยังเปิดอยู่ = หยุดการตัดจบรอบนั้นทั้งหมด
  แจ้ง TG ครั้งเดียว · ถ้าวันถัดไปผังยังบอกให้ตัดการมอบชุดเดิมทุกตัว = ไม่ใช่ผังเพี้ยนชั่วคราว จึงตัดจบตามนั้น
  (จำการหยุดด้วยแถว `notifications` kind `end_held`) · ผู้สร้างกดบันทึกผู้รับเองไม่ติดด่าน เพราะหน้าจอบอกว่า "บันทึกแล้วจะตัดจบ n คน" ก่อนกด
- **หน้ารายชื่อ** (แท็บผู้เรียน · Dashboard ทุกส่วนทุกเดือน) ซ่อนคนลาออกและการมอบที่ตัดจบที่ยังไม่ผ่าน ไปรวมในบรรทัด "ซ่อน n คน · แสดง" ·
  ถามผังไม่ได้ = ไม่ซ่อนเพราะ "ไม่อยู่ในผัง" (ไม่ซ่อนทุกคนเพราะ WorkID ล่ม) · CSV ส่งทุกคนพร้อมคอลัมน์ "อยู่ในผัง" และ "ตัดจบเมื่อ"
- **รวมข้อความต่อคน ต่อรอบ ต่อชนิด** — ชุดใหม่ · ได้รับมอบอีกครั้ง · ไม่ต้องเรียนแล้ว · เตือนวันที่ 3 · เตือนวันที่ 5 แบบตัวต่อตัว ·
  หลายเรื่อง = ข้อความเดียวที่ไล่ชื่อชุด แล้วลงแถวของแต่ละเรื่องว่าส่งรวมแล้ว (`markCoveredBy` / `markSkippedBy`) · ตอนอนุมัติยังส่งทันที

## ไม่เลือก

- **ลบแถวการมอบ** — ผลสอบและสถิติเดือนก่อน ๆ หาย · เปิดใหม่ไม่ได้ (หนึ่งคนหนึ่งแถวต่อชุด)
- **เช็คสดอย่างเดียวไม่บันทึก** — ไม่มีวันที่ตัดจบให้ดู · ผังเพี้ยนชั่วคราวทำให้คนหายแล้วกลับมาเอง
- **ให้ TG กดยืนยันก่อนตัดเมื่อติดด่าน** — ต้องมีหน้าใหม่ · ผังที่ยืนยันซ้ำข้ามวันพอบอกได้ว่าไม่ใช่เพี้ยน
- **เก็บข้อความ "ชุดใหม่" ไว้ส่งรวมรอบเช้า** — ผู้เรียนรู้ช้าไปครึ่งวัน · รวมเฉพาะในรอบเดียวกันก็แก้ปัญหาพนักงานใหม่ได้แล้ว
