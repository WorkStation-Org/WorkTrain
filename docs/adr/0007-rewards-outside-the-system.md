# ADR-0007 — รางวัลประจำเดือนอยู่นอกระบบ · WorkTrain มีแค่ Dashboard และ Leaderboard

วันที่ 25 ตุลาคม 2569 · สถานะ: ใช้อยู่ · ที่มา: grilling เรื่อง WorkTrain รุ่นที่ 1

โจทย์มีรางวัลเดือนละ 3,000 บาทสำหรับคนที่ทำไวและได้คะแนนสูงสุด **ตัดสินว่าการขออนุมัติและการจ่ายรางวัลไม่อยู่ในระบบ** —
TG จัดเองข้าง ๆ จากสถิติ · WorkTrain ให้แค่ Dashboard สรุปตัวเลขและ Leaderboard Top 10 ประจำเดือน

## เหตุผล

1. **ผู้ตัดสินบอกตรง ๆ** ว่าเป็นการจัดกันเองจากการดูสถิติ
2. **กติกาการให้รางวัลเปลี่ยนได้บ่อย** — ฝังในระบบแล้วต้องแก้โค้ดทุกครั้งที่ปรับ

## ไม่เลือก

- **ระบบเลือกผู้ชนะ ส่งขออนุมัติ และประกาศผลเอง** — ตามข้อ 1–2

## ผลที่ตามมา

- ตัวเลขที่ TG ใช้ต้องชัดและ export ได้: คะแนนครั้งแรก · ความไว · จำนวนครั้งที่สอบ · การออกจากหน้าสอบ
- Leaderboard เป็นแรงกระตุ้น ไม่ใช่การประกาศผู้ได้รางวัล
